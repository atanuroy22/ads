What is JSON?

JSON (JavaScript Object Notation) is a lightweight data-interchange format. It is incredibly easy for humans to read and write, and highly straightforward for machines to parse and generate. JSON is a text format that is completely language independent.

It is based on two universal structures:

  • A collection of name/value pairs (often realized as an object, record, struct, dictionary, hash table, keyed list, or associative array).
  • An ordered list of values (often realized as an array, vector, list, or sequence).

Why Format JSON?

Often, APIs or database dumps return JSON in a "minified" format. While efficient for computers, this makes the data nearly impossible for developers to read or debug.

Our formatter instantly parses the raw string and outputs a properly indented, "beautified" version so you can easily trace the hierarchical structure of the data payload.
