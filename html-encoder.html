HTML Entity Encoder & Decoder

Convert special characters to their HTML entity equivalents and back again. This tool helps you safely display user content on web pages without breaking your markup.

What are HTML Entities?

HTML entities are special strings that represent reserved characters in HTML. Because certain characters have special meaning in HTML markup (such as angle brackets for tags), you cannot simply type them directly into your content. Instead, you use entity references to display these characters on the page.

For example, if you want to display a literal less-than sign on your webpage, you would write its entity reference &lt; rather than using the raw character. The browser interprets the entity and renders the correct visual character.

Why Encode HTML Entities?

Encoding HTML entities is essential for security and correct rendering. When user-generated content is placed directly into a page without encoding, it can break your layout or, worse, introduce Cross-Site Scripting (XSS) vulnerabilities.

By encoding special characters, you ensure that content is displayed as plain text rather than being interpreted as executable markup. This is a critical practice for comments sections, search results, any user input fields, and anywhere untrusted data is rendered.

Common HTML Entities

Below is a quick reference of the most commonly used HTML character entities:

  • &lt; represents < (less-than sign)
  • &gt; represents > (greater-than sign)
  • &amp; represents & (ampersand)
  • &quot; represents " (double quotation mark)
  • &#39; represents ' (apostrophe / single quote)
